## Summary
Implement the new responsive **ShipmentDetails** screen at route `/shipment/:id`. The Figma design introduces 238 new nodes across desktop (`1821:351`), tablet (`1845:642`), and mobile (`1845:845`) breakpoints. Because the existing codebase already links to this route from the Dashboard but has no implementation, the plan creates the page component, wires it into the router, and implements the missing backend endpoint and data model.

- **Frontend:** Create the `ShipmentDetails` page component with breadcrumb, progress tracker, timeline, billing, and payment sections; add responsive routing in `App.tsx`.  
- **API:** Verify or create `GET /shipment/:id` to return full shipment lifecycle payloads.  
- **Database:** Create a new `shipments` table (and migration) because the app spec’s data model does not yet include shipments, yet the Dashboard already surfaces shipment IDs.  
- **iOS / Android:** None required — this is a web frontend change rendered inside the Capacitor webview; no native shell modifications are needed.
