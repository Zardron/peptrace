## Frontend Changes

### New files to create
- `frontend/src/components/FormWizard/FormWizard.tsx` — Main wizard container. Accepts optional props (`initialStep`, `onStepChange`, `onComplete`). Maintains `currentStep` state (1–7). Renders `FormProgressSideBar`, conditional step content, and `FormNavNextBack`. Implements responsive layout rules using the project’s existing breakpoint tokens.
- `frontend/src/components/FormWizard/FormProgressSideBar.tsx` — Sidebar containing `FormProgressNavigation` (a list of `FormWizardNavItemButton` instances) and `CartProgress` (price label + value). On mobile (`0px – 754px`) transforms into a compact step indicator; on desktop (`755px – 1118px`) and tablet (`1119px+`) renders as a left-hand two-column sidebar.
- `frontend/src/components/FormWizard/FormWizardNavItemButton.tsx` — Nav item button reused across all steps. Displays step label and a vector checkmark for completed steps. Props: `label`, `isActive`, `isCompleted`, `onClick`.
- `frontend/src/components/FormWizard/FormNavNextBack.tsx` — Shared bottom action bar. Props: `onBack`, `onNext`, `nextLabel` (default `"Next"`, Ship step uses `"Register Shipment"`), `showSkip` (Proof step), `onSkip`. Includes left/right arrow vector icons.
- `frontend/src/components/FormWizard/FormWizard.css` — Component-scoped styles for the three breakpoint layouts, step transitions, and spacing derived from Figma auto-layout.
- `frontend/src/components/FormWizard/index.ts` — Barrel export.

### Step content
Implement the seven step-specific content frames conditionally inside `FormWizard.tsx` based on the active step index:
1. **Choose Product** — `FreeTestingTitle`, product select (chip row + paid product list), quantity selector.
2. **Testing Options** — `TestingOptionsContainer`, free-testing label, HPLC details, add-on test option cards (`Test#Standard`, `OptionPrice`, `OptionDetailsContainer`).
3. **Vendors** — `FormFields`, vendor search list rows.
4. **Batch Info** — `FormFactorSelection` (`LypholizedPowder`, `ReconstitutedPeptide`, `SprayGelLiquid`, “Other”), batch identifier input, batch identifier proof file upload, quantity (mg).
5. **COA** — `COAContent`, `DidVendorProvideCOA` (Yes/No), `VendorCOAProvidedWhen` radio group (During purchase / Vendor’s Website / With the shipment / QR code / Another way + text input), `DoesCOAAndBatchIdMatch` (Yes/No), COA upload (URL + file).
6. **Proof** — `Proof of Purchase` title, file upload, `Order Details` (Order ID, Order Date with calendar icon, Number of vials, Price per vial with USD selector). Action bar shows `Skip`.
7. **Ship** — `ConfirmShipment` with `ShipmentDetailsList` (editable rows: Product, Vendor, Form Factor, Batch ID, COA, Proof of Purchase, Purchase Details, Satisfaction), `AddSampleRow`, `EndotoxinSection`, `PaymentCard` (Lab Choice, Private, Total), `TurnaroundSection`, `WarningBanner` (dismissible), `TermsAndConditionsBox` (3 checkboxes + newsletter opt-in), `FooterLinks`. Action bar uses `Register Shipment`.
