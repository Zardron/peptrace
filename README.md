# Peptrace

Hybrid web / iOS / Android app. The UI and routes are being designed and will be
built by the Esteemed AI Software Factory; this repo currently contains the
starter shell they will build on.

## Structure

- `frontend/` — React + TypeScript + Vite web app, wrapped with [Capacitor](https://capacitorjs.com/)
  for iOS and Android. The native projects live in `frontend/ios/` and `frontend/android/`.
- `admin/` — built admin panel bundle at the repo root.
- `api/` — Express + TypeScript backend server (Dockerized). Business logic and
  routes will be added by the AI Software Factory. Service bundles are grouped in
  `api/services/` by admin panel, projects, and shared userbase ownership.

## App identity

- App name: **Peptrace**
- App ID: `com.esteemed.peptrace` (see `frontend/capacitor.config.ts`)

## Getting started

```bash
cd frontend
npm install
```

### Web

```bash
npm run dev      # dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

### iOS

Requires macOS with Xcode and CocoaPods/SPM support.

```bash
npm run build
npx cap sync ios
npx cap open ios   # opens Xcode; run on a simulator or device from there
```

### Android

Requires Android Studio with an SDK installed.

```bash
npm run build
npx cap sync android
npx cap open android   # opens Android Studio; run on an emulator or device
```

### Workflow notes

- Always `npm run build && npx cap sync` after changing web code or Capacitor
  plugins so the native projects pick up the latest `dist/`.
- `frontend/ios/` and `frontend/android/` are committed; their build outputs are
  git-ignored.
- UI screens and routing are intentionally not implemented yet — they will be
  generated by the AI Software Factory.
